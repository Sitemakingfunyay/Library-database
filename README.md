# Library-database

A simple library system for managing books at home and tracking who has checked them out.

## My Books

- The complete list of books I own
- Each book can be marked as available or checked out
- A quick way to see what I have in my collection

## Check In / Check Out

Use the system to track the status of every book:
- Check out a book when it is borrowed
- Check in a book when it is returned
- Keep a record of current availability

## Available Books

This section shows which books are currently available to borrow.
